Loja de Maquiagem Cherry Make- Projeto final 3º ano Informática Manhã

 🍒 Cherry Make

Sistema web desenvolvido para a **Cherry Make**, uma loja de maquiagem de marca própria.

 📌 Sobre o Projeto

O projeto tem como objetivo centralizar o gerenciamento da loja e oferecer uma **loja virtual**, facilitando o controle de produtos, estoque, vendas, fornecedores e clientes.

 ✨ Funcionalidades

- Cadastro e gerenciamento de produtos;
- Controle de estoque;
- Cadastro de categorias e fornecedores;
- Registro de entradas e vendas;
- Gerenciamento de clientes;
- Loja virtual com carrinho;
- Controle de usuários e permissões;
- Relatórios de vendas;
- Registro de notas fiscais.

 🎨 Identidade Visual

O sistema utiliza a identidade visual da Cherry Make, com uma estética moderna baseada em tons de **rosa e cereja**.

 👩‍💻 Projeto Acadêmico

Projeto desenvolvido para fins acadêmicos, com o objetivo de aplicar conhecimentos de **análise de sistemas, banco de dados, desenvolvimento web e engenharia de software**t.
