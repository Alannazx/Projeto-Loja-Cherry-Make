Loja de Maquiagem Cherry Make- Projeto final 3º ano Informática Manhã

A Cherry Make é um sistema web desenvolvido para uma loja de cosméticos e maquiagem, com o objetivo de facilitar a organização e o gerenciamento do negócio. O sistema reúne funções como cadastro de produtos, categorias, fornecedores, controle de estoque, vendas, clientes e notas fiscais. 
Além da área interna, o projeto possui uma loja virtual, onde os clientes podem visualizar produtos, pesquisar, filtrar por categorias, adicionar itens ao carrinho e realizar compras.
O principal objetivo é substituir os controles manuais por um sistema organizado, seguro e eficiente, facilitando o gerenciamento da loja e proporcionando uma melhor experiência aos clientes.
